# PCSweep 2.0.0

- **Explorer recovery.** Restore the taskbar or restart Explorer through the signed-in Windows desktop. The recovery helper starts in that session before an existing shell is stopped. PCSweep waits for the new taskbar and reports where Windows refused an operation.
- **Run apps with Ctrl+R.** Search installed apps by name, enter a command and arguments, paste a path or web address, or browse for a file. PCSweep hands the request to the Windows desktop under the signed-in account.
- **Review the Recycle Bin.** See original names, folders, sizes, and deletion dates. Search, sort, and select items for removal. Only selected entries that still match the review are deleted, and the Cleanup history records each attempted removal.
- **An HTTPS speed test that shows its work.** Cloudflare measures download, upload, and latency with separate results and bounded test traffic. Quick and Longer runs support cancellation, optional session history, and a browser test link.
- **Distinct themes.** Frosted glass and Aero have layered highlights and translucent panels. Retro desktop adds square bevels and a navy title strip. Cobalt has glossy blue chrome and classic Windows typography. Sakura features an original illustrated landscape, while Neon circuit has a glowing grid. Text size, bold text, and High contrast remain available.
